# Brand colors

Luxury black and white, with small accents. Rule from the project owner (2026-10-27): the palette is monochrome; other colors appear only in small amounts.

| Role | Hex | Use |
|---|---|---|
| Black | `#050505` | page / video background |
| Panel | `#0C0C0D`-`#161618` | cards, terminal window |
| Line | `#2A2A2E`-`#3A3A40` | borders, default graph nodes |
| White | `#F5F5F4` | primary text, highlighted nodes |
| Grey | `#A1A1AA`, `#8A8A92`, `#6B6B72` | secondary text, paths, dim labels |
| Accent orange | `#FF5A1F`, `#FF8A4C` | taken from the logo; small marks only: step labels, chips, prompts, key numbers, the changed node |

Avoid: large orange fills, multicolor emoji, blue/indigo/green (the older indigo artwork — `wordmark*.svg`, `logo.svg` and the README demo `docs/demo-search.svg` — predates this rule and has not been recolored; `hero*.svg` was recolored 2026-10-29 and embeds `logo.png`).

The logo (`logo.png`) is the one place orange is large; it supplies the accent.
